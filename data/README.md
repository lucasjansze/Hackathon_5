**What we changed.** This is a subset. It contains only respondents from the Netherlands (`cntry = NL`) and only these variable groups: *Gender, age and household composition*, *Socio-demographic profile*, *Subjective well-being, social exclusion; religion; perceived discrimination; national and ethnic identity* and *Region*, plus the administrative variables the portal always includes. We did not change any values. All cleaning happens inside the notebook.
